📱 API ENDPOINTS
================

Auth Service (Port 8081)
  POST   /api/auth/register     - Register new user
  POST   /api/auth/login        - Get JWT token

Product Service (Port 8082)
  GET    /api/products           - List all (cached)
  GET    /api/products/{id}      - Get product (cached)
  POST   /api/products           - Create (admin only)
  PUT    /api/products/{id}      - Update (admin only)
  PUT    /api/products/{id}/stock - Update stock

Order Service (Port 8083)
  POST   /api/orders             - Create order (JWT required)
  GET    /api/orders/{id}        - Get order
  GET    /api/orders/user/{userId} - List user orders

User Service (Port 8084)
  GET    /api/users/{userId}           - Get profile (public)
  POST   /api/users                    - Create profile
  PUT    /api/users/{userId}           - Update (JWT required)
