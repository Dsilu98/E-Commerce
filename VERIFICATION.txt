LOCAL DEVELOPMENT:

2. Install prerequisites (Java 17, Maven, Docker)
3. Follow docs/SETUP.md for environment setup
4. Run: docker-compose up postgres redis rabbitmq
5. Run each service in IntelliJ (see README for configs)

DOCKER DEPLOYMENT:
1. Navigate to E-Commerce directory
2. Run: docker-compose up --build
3. Access services at specified ports
4. Monitor via Prometheus (localhost:9090)
5. Dashboard via Grafana (localhost:3000)

QUICK TEST COMMANDS:
# Register user
curl -X POST http://localhost:8080/auth/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"user1","email":"user1@test.com","password":"pass123"}'

# Login & get token
curl -X POST http://localhost:8080/auth/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user1","password":"pass123"}'

# Create product (with admin token)
curl -X POST http://localhost:8080/products/api/products \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"name":"Laptop","description":"Test","price":999.99,"stock":10}'

# Create order (with JWT token)
curl -X POST http://localhost:8080/orders/api/orders \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"items":[{"productId":1,"quantity":2}]}'
